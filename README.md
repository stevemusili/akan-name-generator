# akan-name-generator

## Description
A web application that calculates the day of the week a user was born and assigns them an Akan name based on their gender.

## Author
Steve Musili

## Set-up Instructions
1. Git clone the repository
https://github.com/stevemusili/akan-name-generator.git

2. Access the project folder.

3. Open index.html on your browser.

## BDD (Behavior-Driven Development)
| Behaviour | Input | Output |
| Enter valid birthday | 29/2/2024 Male| Yaw |
| Enter invalid month | 13 | Alert |
| Enter invalid day | 35 | Alert |
| No gender selected | None | Alert |
